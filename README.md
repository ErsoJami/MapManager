# Обзор приложения MapManager

"MapManager" – это Android-приложение, предназначенное для планирования и участия в групповых поездках и мероприятиях, основанных на пользовательских маршрутах.

## Основные функции:

### 1. Карта и маршрутизация
*   **Интерактивная карта:** Использует Yandex MapKit для отображения интерактивной карты.
*   **Создание пользовательских маршрутов:** Позволяет пользователям создавать подробные маршруты, размещая несколько путевых точек непосредственно на карте.
*   **Различные виды транспорта:** Рассчитывает маршруты для различных видов транспорта, включая автомобили, общественный транспорт (автобусы), пешие прогулки и велосипеды.
*   **Сохраненные маршруты:** Пользователи могут сохранять свои пользовательские маршруты в личном кабинете, все данные хранятся в Firebase.

### 2. Социальные мероприятия ("Карточки маршрутов")
*   **Публикация мероприятий:** Пользователи могут публиковать свои сохраненные маршруты в виде "Карточек маршрутов", которые служат публичными объявлениями о поездке или мероприятии по данному маршруту.
*   **Детали мероприятия:** При создании Карточки маршрута пользователи могут указывать такие детали, как название, описание, дата, время начала/окончания, целевой город и рекомендуемый возрастной диапазон для участников.
*   **Групповой чат:** Для каждой Карточки маршрута автоматически создается выделенный групповой чат, обеспечивающий общение между участниками.

### 3. Открытие и участие
*   **Лента мероприятий:** Главный экран отображает ленту публичных Карточек маршрутов, позволяя пользователям находить предстоящие поездки и мероприятия, созданные другими.
*   **Поиск и фильтрация:** Предоставляет функциональность для поиска Карточек маршрутов по названию и их фильтрации по таким критериям, как город, длина маршрута и возраст участников.
*   **Присоединение к мероприятиям:** Пользователи могут присоединиться к любой публичной Карточке маршрута, что автоматически добавляет их в групповой чат мероприятия для координации с другими участниками.

### 4. Управление пользователями и данными
*   **Аутентификация:** Использует Firebase Authentication для регистрации и входа пользователей.
*   **Профили пользователей:** У каждого пользователя есть профиль, в котором хранятся его личные данные и список сохраненных маршрутов.
*   **Бэкенд:** Использует Firebase Realtime Database для хранения и синхронизации всех данных приложения, включая профили пользователей, маршруты, карточки маршрутов и сообщения чата.

Таким образом, MapManager – это социальное картографическое приложение, которое сочетает планирование маршрутов с организацией мероприятий, позволяя пользователям создавать, делиться и присоединяться к групповым активностям, сосредоточенным вокруг определенного пути или путешествия.
